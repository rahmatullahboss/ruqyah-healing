# AI Bridge

Shared planning context for ChatGPT, other planning models, and Codex.

- current-plan.md: plan produced by ChatGPT or another planning model for Codex to execute.
- codex-status.md: implementation notes and test results from Codex.
- decisions.md: architectural decisions that should remain stable.
- open-questions.md: unresolved questions.
- session-log.jsonl: append-only session events.
